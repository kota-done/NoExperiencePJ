# クラス設計一覧

## ドメインモデル
### DirectEmployee
- id: long
- firstName: String
- lastName: String
- email: String
- status: DirectEmployeeStatus
- clientCompany: ClientCompany

### ClientCompany
- id: long
- companyName: String
- charge: BigDecimal
- prefectureName: String
- contactEmail: String
- phoneNumber: String
- businessStatus: BusinessStatus

### DirectEmployeeStatus
- ON_ASSIGNMENT
- WAITING
- LEAVE_OF_ABSENCE
- TRAINING

### BusinessStatus
- ACTIVE
- SUSPENDED
- CLOSED

## Service
### DirectEmployeeService
- getAllDirectEmployees(): List<DirectEmployee>
- 引数: なし / 戻り値: 従業員一覧
- saveDirectEmployee(DirectEmployee employee): void
- 引数: employee / 戻り値: なし
- getDirectEmployeeById(long id): DirectEmployee
- 引数: id / 戻り値: 対象従業員
- deleteDirectEmployeeById(long id): void
- 引数: id / 戻り値: なし
- findPaginated(int pageNo, int pageSize, String sortField, String sortDirection): Page<DirectEmployee>
- 引数: pageNo, pageSize, sortField, sortDirection / 戻り値: ページング結果

### ClientCompanyService
- getAllClientCompanies(): List<ClientCompany>
- 引数: なし / 戻り値: 派遣先企業一覧
- saveClientCompany(ClientCompany clientCompany): void
- 引数: clientCompany / 戻り値: なし
- getClientCompanyById(long id): ClientCompany
- 引数: id / 戻り値: 対象派遣先企業
- deleteClientCompanyById(long id): void
- 引数: id / 戻り値: なし

### ClientCompanyRepository
